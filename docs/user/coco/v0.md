# Connect v0

CoCo's beta v0 integration currently supports account connection and diagnostics in the Windows and macOS desktop app. Chat integration is pending compatibility verification. It does not yet make v0 available to chat or generate prototypes.

## Connect your account

Open [Settings → Integrations → v0](/settings/integrations#v0), select **Connect**, and complete authorization in your browser. Use your organization's SSO if v0 requires it. Return to CoCo to read the result.

Choose the account and team you intend to use during authorization. A successful sign-in does not establish access to every team or feature. The connection is saved on this desktop; another machine needs its own sign-in. The web development client cannot establish this desktop connection.

**Signed in · tool discovery passed** means the latest check discovered v0's advertised tools. **Signed in · connection not yet verified** means a saved sign-in exists, but a successful check is still needed. Neither status means a tool has been tested or v0 is ready to use in CoCo chat.

## Check or repair the connection

Use **Test connection** to check saved access. Opening Settings does not automatically run a network test. A successful connection check does not guarantee that every advertised v0 tool will work.

If CoCo requests additional authorization or reports an expired sign-in, select **Reconnect** and complete the browser flow again. Use **Cancel sign-in** to stop an incomplete authorization attempt. Canceling a reconnect retains the previously saved connection.

For a failed connection, expand **Connection diagnostics** and copy the report when asking for help. The report omits credentials and prototype content. If sign-in never opens or cannot finish, check your network connection and any organization sign-in requirements before retrying.

## Disconnect

Select **Disconnect** to remove the encrypted connection saved on this device. This does not delete v0 projects or revoke any separately connected tools. To revoke the authorization itself, use your account's authorization settings.
